# Manage-Task (MT) — Project Description for CV

## Overview

Web-based task/project management application (similar to Trello/Jira). Manage projects, boards, lists, tasks with real-time collaboration, RBAC, and notifications.

**Features:** Auth (JWT + OTP), Kanban boards (drag & drop), real-time updates (WebSocket), notifications, task scheduling, activity logging.

---

## Frontend (FE)

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, Zustand, TanStack React Query, React Hook Form, Zod, React Router, Socket.IO Client, Axios, @dnd-kit

---

## Backend (BE)

Node.js, Express, TypeScript, Prisma, PostgreSQL, Socket.IO, JWT, Zod, Swagger, Nodemailer, Cloudinary, Docker

---

## Role

Full-Stack Developer — designed and implemented both frontend and backend from scratch.
