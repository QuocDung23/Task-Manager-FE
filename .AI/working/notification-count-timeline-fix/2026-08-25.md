# Notification Count & Timeline Error Fix - 2026-08-25

## Issues Fixed

### [P2] handleReadAll - Unread count reconciliation

**File:** `FE/src/features/realtime/handlers/notification-event-handlers.ts`

**Problem:** `handleReadAll` dùng `affectedCount` từ số item trong cache để set unread count, dẫn đến badge sai khi:
- Unread list chưa load hết
- Unread list chưa được cache

**Fix:** Thay `setQueryData` bằng `invalidateQueries` để luôn reconcile với server.

```ts
// Before (buggy):
if (affectedCount > 0) {
  queryClient.setQueryData<UnreadCountResponse>(
    notificationKeys.unreadCount(),
    (current) => ({
      success: true,
      data: { count: Math.max(0, (current?.data.count ?? 0) - affectedCount) },
    }),
  );
}

// After (fixed):
void queryClient.invalidateQueries({
  queryKey: notificationKeys.unreadCount(),
});
```

### [P2] Timeline - Error khi một trong hai query thất bại

**File:** `FE/src/components/tasks/comments/task-comments-section.tsx`

**Problem:** Error state chỉ hiện khi **cả hai** queries cùng lỗi (`isError && activityQuery.isError`). Nếu một lỗi, một thành công, UI im lặng render thiếu dữ liệu.

**Fix:** Đổi thành OR condition để hiện error khi **bất kỳ** query nào thất bại.

```diff
- ) : isError && activityQuery.isError ? (
+ ) : (isError || activityQuery.isError) ? (
```
