## Issues Fixed

### P2: Khôi phục legacy listener `notification:new`

**File:** `FE/src/features/realtime/hooks/useTaskSocket.ts`

**Mô tả:** FE đã xóa listener `notification:new` trong khi BE vẫn emit event này trong `notifyTaskRecipients`. Điều này làm assignee online không nhận được toast realtime khi task được schedule lần đầu.

**Thay đổi:**
- Thêm handler `handleLegacyNotification` với type check `payload.type.startsWith("TASK_")`
- Register listener với `socket.on("notification:new", handleLegacyNotification)`
- Cleanup đúng reference trong return function

### P3: Loại item đã đọc khỏi cache unread

**File:** `FE/src/features/realtime/handlers/notification-event-handlers.ts`

**Mô tả:**
- `updateLists` không biết context filter (`all`/`unread`) nên chỉ map items
- Item có `readAt !== null` vẫn còn trong cache `unread` sau khi mark read
- `handleReadAll` có cùng lỗi với mark-all-read

**Thay đổi:**
1. Cập nhật `updateLists` để nhận filter từ query key
2. `handleReadState`: Với `filter === "unread"` và `readAt !== null` → filter bỏ item
3. `handleReadAll`: Với `filter === "unread"` → filter bỏ tất cả item thỏa điều kiện
4. Thêm `invalidate` cho mark unread case (`readAt === null`)
